APK HUB - FREE STATIC VERSION

This is a simple APK download website.

HOW TO ADD AN APP:
1. Put your APK inside an "apks" folder.
2. Put its icon inside an "icons" folder (optional).
3. Open apps.js.
4. Add an object like:
   {name:"My App",version:"1.0",size:"25 MB",description:"My app description",icon:"icons/my-app.png",file:"apks/my-app.apk"}
5. Upload the whole folder to your static hosting service.

IMPORTANT:
- This version has no virus scanning.
- It does not include a server-side admin panel.
- For a truly free setup, use a static hosting service that allows your files and bandwidth.
- Only upload APKs you have the right to distribute.
